PERBAIKAN NOTIFIKASI PERMOHONAN TAQWIMUPA v2.6

Penyebab: fungsi esc() dipanggil saat merender daftar pemohon tetapi belum didefinisikan. Akibatnya penghitung tampil, sementara kartu pemohon gagal dirender.

Pemasangan:
1. Buka repository GitHub 1650afr/Taqwim.
2. Buka file firebase.js di folder utama.
3. Pilih Edit (ikon pensil).
4. Ganti seluruh isi firebase.js dengan file firebase.js dari ZIP ini.
5. Commit perubahan ke branch main.
6. Tunggu GitHub Pages selesai deploy, lalu buka ulang aplikasi. Jika masih memakai cache, refresh paksa atau buka tab samaran.

JANGAN mengganti index.html, app.js, forms-data.js, Firebase config, atau Firestore Rules untuk perbaikan ini.

Setelah daftar muncul, tombol Setujui permohonan hanya mengubah status menjadi approved. Tombol itu BELUM membuat akun Firebase atau memberikan role otomatis.
